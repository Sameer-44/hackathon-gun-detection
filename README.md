# 🔫 Hackathon Gun Detection

A computer vision project developed as a team project for detecting guns using **YOLO** and **OpenCV**. The project includes datasets, trained model weights, inference videos, utility files, and training results.

## 📌 Project Overview

The objective of this project is to explore computer vision techniques for gun detection from images and video.

The project uses YOLO-based models for object detection/classification and OpenCV for computer vision and video-processing tasks.

## 🚀 Features

- Gun detection using YOLO
- Image/video-based inference
- OpenCV-based computer vision processing
- YOLO model training and evaluation
- Training results and performance visualizations
- Pre-trained model weights included
- Test videos included for inference

## 🛠️ Technologies Used

- **Python**
- **YOLO / Ultralytics**
- **OpenCV**
- **Computer Vision**
- **Deep Learning**
- **Java**
